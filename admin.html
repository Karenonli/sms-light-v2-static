🔐 Настройка SMTP
Для отправки писем через Mail.ru / inbox.ru требуется пароль приложения

1. Перейдите в настройки Mail.ru → Безопасность → Пароли для внешних приложений

2. Создайте «Пароль для внешнего приложения»

3. Скопируйте его в SMTP_PASS в файле .env

⚠️ Обычный пароль от почты НЕ подходит — Mail.ru блокирует SMTP-вход без пароля приложения.

SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=your@mail.ru
SMTP_PASS=пароль_приложения
SMTP_FROM="SMS Light" <your@mail.ru>
